# InstantMatrimony V2 Enterprise - Administrator Manual

## Admin Panel Modules
- **/admin/settings**: White-label branding, logos, theme colors, contact info, SEO metadata, locale & currency.
- **/admin/rbac**: Role-Based Access Control matrix for Super Admin, Moderator, Finance, and Customer Support roles.
- **/admin/cms**: Dynamic content management for Hero, Banners, FAQs, Testimonials, Success Stories, and Blog.
- **/admin/email-templates**: Visual HTML/text template editor with variable placeholders, live preview, and test emails.
- **/admin/notifications**: Per-event multi-channel toggle matrix (Email, SMS, WhatsApp, Push, In-App).
- **/admin/providers**: Payment provider configuration (Manual QR, Bank Transfer, Cashfree, PhonePe, Stripe), Storage layer (Local, Cloudinary, S3), and SMS/WhatsApp layer.
- **/admin/reports**: Analytics dashboard with visual metrics and CSV export.
- **/admin/audit-logs**: Audit log viewer with user, action, module, and IP filters.
- **/admin/system-health**: Diagnostic status monitor for CPU, RAM, database, queue, and SMTP.
- **/admin/backups**: Backup snapshot manager and database restoration.
- **/admin/license**: Commercial license details.
- **/admin/plugins**: Plugin registry for optional extensions.
