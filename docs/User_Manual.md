# InstantMatrimony V2 Enterprise - User Manual

## End-User Capabilities
1. **Registration & Profile Wizard**: Step-by-step profile creation covering personal details, caste, religion, education, occupation, and photos.
2. **Search & Filters**: Advanced matchmaking search by age, height, location, education, and marital status.
3. **Interests & Messaging**: Express interest, accept/decline requests, and real-time chat.
4. **Membership Plans**: Upgrade plans via manual bank/QR payment or dynamic payment gateways.
5. **Privacy Controls**: Photo blur, contact number hiding, and profile privacy options.
