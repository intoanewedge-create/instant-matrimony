# InstantMatrimony V2 Enterprise Commercial Release Notes

## Release Highlights (v2.0.0-ENTERPRISE)
- **White-Label Platform Engine**: Full runtime dynamic branding, logos, theme colors, typography, currency, and locale customization without code changes or rebuilds.
- **Dynamic CMS**: Comprehensive manager for FAQs, Banners, Testimonials, Success Stories, and Blog.
- **RBAC**: Multi-role permission matrix supporting Super Admin, Moderator, Finance, and Customer Support.
- **Notification Center**: Event-based channel toggles (Email, SMS, WhatsApp, Push, In-App).
- **Email Template Builder**: Visual HTML/text template editor with variable placeholders, live preview, versioning, and test mail delivery.
- **Provider Architecture**: Support for Manual QR Code, Bank Transfer, Cashfree, PhonePe, Stripe, Cloudinary, AWS S3, MSG91, TextLocal, Twilio, and Meta WhatsApp API.
- **Analytics & Reports**: Visual chart metrics and CSV export engine.
- **System Health & Backups**: Health dashboard and backup snapshot generator/restorer.
- **Installer Wizard**: First-run setup wizard at `/installer` with automatic lock upon completion.
- **Documentation Suite**: 10 comprehensive guides generated under `docs/`.
